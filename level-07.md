# Level 7

## Goal
Find the password next to the word "millionth" in a huge data file.

## What I Used
- `grep` — searches for a specific word or pattern in a file

## Solution
`grep millionth data.txt`

## What I Learned
grep is the single most-used command in SOC work. Searching through massive log files for a specific IP, username, error code, or indicator of compromise — that's grep. This one command will be in almost every investigation you run.
